# AI/ML Club - University of Toledo

A modern, responsive website for the AI/ML Club at the University of Toledo. Built with React and Vite for fast development and optimal performance.

## 🚀 Features

- **Modern UI**: Clean and responsive design
- **Component-Based Architecture**: Modular React components for easy maintenance
- **Sections**:
  - Home screen with hero section
  - About Us section
  - Events showcase
  - Members directory
  - Contact information

## 🛠️ Tech Stack

- **React 19** - UI library
- **Vite** - Build tool and dev server
- **CSS3** - Styling
- **ESLint** - Code linting

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/AI-ML-Club-UToledo/ai-ml-club-website.git
cd ai-ml-club-website
```

2. Install dependencies:
```bash
npm install
```

## 🎯 Getting Started

1. Start the development server:
```bash
npm run dev
```

2. Open your browser and navigate to the URL shown in the terminal (typically `http://localhost:5173`)

3. Build for production:
```bash
npm run build
```

4. Preview the production build:
```bash
npm run preview
```
